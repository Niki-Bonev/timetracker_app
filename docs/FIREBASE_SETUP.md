# Firebase setup

Tempo intentionally builds without Firebase configuration. Add this only when you want sign-in and cloud sync.

1. Create a Firebase project.
2. Add an Android app with package name `com.nikibonev.tempo`.
3. Download `google-services.json` and place it at `app/google-services.json` (it is gitignored).
4. In Firebase Authentication, enable **Email/Password** and **Google** providers.
5. Add the SHA-1 and SHA-256 fingerprints for your debug certificate and, before release, your Play App Signing certificate / upload certificate as appropriate.
6. Re-download `google-services.json` after enabling/configuring Google sign-in so the OAuth client data is present.
7. Create a Cloud Firestore database.
8. Publish the included `firestore.rules`.

## Firestore layout

Tempo writes only beneath:

```
users/{uid}
users/{uid}/projects/{projectId}
users/{uid}/sessions/{sessionId}
users/{uid}/intervals/{intervalId}
```

The supplied rules restrict each tree to the matching authenticated UID.

## Email verification

New email/password accounts get a Firebase verification email. Tempo does not block the timer while verification is pending; authentication is a backup/sync feature, not a prerequisite for tracking.

## Google sign-in

The app uses Android Credential Manager + Firebase Authentication. The web OAuth client ID generated by Firebase is read from the Google Services resources; no OAuth secret is hardcoded in source.
